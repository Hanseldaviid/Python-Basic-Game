# 🎮 Rock, Paper, Scissors Game in Python

A classic, interactive **Rock, Paper, Scissors** console game developed in Python. This project was built to practice programming logic, control flow, exception handling, and loops.

## 🚀 Features
- **Interactive Menu:** Clear choices to select Rock, Paper, Scissors, or Exit.
- **Random AI Opponent:** The computer makes random selections using Python's built-in `random` module.
- **Input Validation & Error Handling:** Robust `try-except` blocks to prevent the program from crashing if the user enters letters or invalid inputs instead of numbers.

## 🛠️ Tech Stack
- **Language:** Python 3.10+
- **Built-in Modules:** `random`
